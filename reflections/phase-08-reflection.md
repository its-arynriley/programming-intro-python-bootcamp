## What I would improve next

## Key takeaway

Streamlit turns Python code into a browser app that is easier to share and demo.

## What Streamlit is

Streamlit is a Python library for building simple web apps.

## What localhost means

Localhost is an address that points to an app running on my own computer.

## How a terminal app differs from a browser app

A terminal app uses typed prompts and text output. A browser app can use widgets, tables, metrics, and charts.
