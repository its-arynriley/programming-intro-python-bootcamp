## Key takeaway

Deploying an app is important because it allows others to use it, but the project should be checked before it is public.

## What deployment means

Deployment means putting an app somewhere other people can access it.

## What public repo readiness means

Public repo readiness means the project is organized, documented, and clean enough to share publicly in a GitHub repository.
